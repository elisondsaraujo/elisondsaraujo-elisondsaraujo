### Projeto em destaque

**API de Autenticação**

Sistema back-end em **Java e Spring Boot**, com foco em segurança, organização e boas práticas.

- **Autenticação:** cadastro e login com JWT
- **Autorização:** Spring Security, perfis `USER` e `ADMIN`
- **Dados:** PostgreSQL, validação e tratamento de exceções

```text
Client → Controller → Service → Repository → PostgreSQL
```
